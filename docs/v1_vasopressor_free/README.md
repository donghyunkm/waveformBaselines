# v1 Vasopressor-Free Raw-Waveform Baselines

This folder tracks the original vasopressor-free raw-waveform PatchTST workstream: dataset descriptions, target generation, training/evaluation notes, and regression/classification results for the v1-style baseline runs.

Use this folder when comparing against the earlier leakage-safe vasopressor-free `patchtst_v1` experiments or checking how the original raw-waveform targets were defined.

Key docs:

- `training.md`: core raw-waveform training pipeline and model variants.
- `training_vaso_free.md`: vasopressor-free cohort training jobs and outcomes.
- `model_description.md`: PatchTST architecture variants.
- `target_generation.md`: event and regression target build logic.
- `regression_results_v1_vaso_free_sorted.md`: main v1 vasopressor-free regression results.
- `classification_results_v1_vaso_free.md`: main v1 vasopressor-free classification results.
