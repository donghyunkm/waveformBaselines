## Regression Target Comparability

Unlike the classification targets, the v7 and full-data regression targets use the same target semantics. Both predict future physiological/source feature values with `gap` timing, where `target_center = anchor_center + input_window_minutes + horizon_minutes`. With the 20-minute input window, `t+0m_gap` therefore points to the target window immediately after the input window, not to an overlapping center-time target.

The differences are cohort and alignment machinery rather than target definition. This v7 bundle uses the older vasopressor-free overlap cohort and aligns future source rows by `(patient_id, anchor_time)`; the full-data bundle uses the segment-aware full-data cohort and aligns by `anchor_id`/segment-aware source identity because full-data anchor times are segment-relative and can repeat within a patient.

## Results Analysis

Across the completed v7 runs, XGBoost variants remain the strongest overall model family, but the metric-specific table is more precise than a single winner label. By `R2`, history XGBoost is best for `10/26` targets, full-sequence XGBoost for `7/26`, Transformer for `5/26`, GRU for `2/26`, TCN for `2/26`, and full-sequence MLP for none. By `MAE`, the winners differ on several targets, including `DBP`, `SBP`, `ABP_area`, `MAP`, `PVI`, `ABP_tau`, `ECG_Ramp`, `ShockIdx_ABP_tau`, and `dPdt_max`.

The neural sequence models still matter for selected metric-specific wins. By `R2`, GRU is best for `dPdt_max` and `ABP_tau`, while Transformer is best for `SBP`, `MAP`, `PLETH_ACDC`, `PLETH_amp_ShockIdx`, and `PTT`. Some sequence wins are metric-specific only: for example, Transformer gives the lowest `DBP` MAE while TCN gives the best `DBP` R2/RMSE, and Transformer gives the lowest `dPdt_max` MAE while GRU gives the best `dPdt_max` R2/RMSE. The sequence-vs-nonsequence table above shows these advantages are small and not statistically significant against the strongest learned non-sequence comparator.

Current-state XGBoost remains a useful baseline but is not a metric-specific winner once history XGBoost, full-sequence XGBoost, neural sequence models, and TCN are included. Full-sequence MLP is not best by `R2` or `RMSE`, but it has the lowest `ABP_tau` MAE. The gap between current-state and history XGBoost is especially informative for targets like `HR`, `PLETH_ACDC`, `PPV`, `RR`, and `RESP_amp`, where short history context substantially improves over a single-window feature snapshot.

Relative to the prior raw-waveform `patchtst_v1` baseline, the best completed v7 model improves `R2` on `25/26` targets. The only remaining degradation is `ECG_Ramp`, where the best v7 result is history XGBoost at `R2=0.320` versus PatchTST `R2=0.356`. The largest gains are for targets that were weak under PatchTST but become learnable from explicit waveform features, especially `RESP_amp` (`+0.698`), `PLETH_ACDC_PLETH_amp` (`+0.472`), and `RR` (`+0.415`). This supports treating the v7 engineered feature cache as a strong regression baseline, with the caveat that final interpretation should still account for the ECG/ABP rate-disagreement audit noted in `docs/v7_extracted_features/extractedFeatures.md`.
