# v7 Extracted-Feature Models

This folder tracks the engineered waveform-feature workstream for the non-full-data v7 cohort. These experiments use extracted physiological features rather than raw waveform tensors.

Use this folder for v7 feature extraction notes, downstream extracted-feature model descriptions, standard-cohort regression/classification results, and agreement analyses.

Key docs:

- `extractedFeatures.md`: v7 feature extraction pipeline and quality notes.
- `extractedFeaturesVerification.md`: v7 feature verification, smoke/full-cohort audit evidence, plots, and known caveats.
- `extractedFeaturesModelDescription.md`: downstream model families for extracted features.
- `extractedFeaturesRegression.md`: v7 extracted-feature regression results.
- `extractedFeaturesClassification.md`: v7 extracted-feature classification results.
- `bland_altman_analysis.md`: agreement-analysis notes and outputs.
- `v8_supplemental_features.md`: supplemental waveform features designed to join with frozen v7 caches without duplicating v7 columns.
